Syllabus#

Machine Learning for Neuroscience · Course 1501.1027 · Semester A, 2026-27 Mondays, 08:30-11:00, Dan David building, room 110

Aims and prerequisites#

  • Core methods and terminology in machine learning

  • Hands-on training, evaluation, and interpretation of common models

  • Uses and challenges of machine learning in neuroscience

Prior Python programming experience is required. A background in probability and linear algebra is recommended.

Course text and scope#

The course covers core machine-learning topics starting from exploratory data analysis, through classification and regression with linear models and KNN, tree-based models, and regularization methods. The course also covers clustering and dimensionality reduction. Hands-on practical work is emphasized throughout.

Course text (freely available): Gareth James, Daniela Witten, Trevor Hastie, Robert Tibshirani, and Jonathan Taylor (2023). An Introduction to Statistical Learning: with Applications in Python. See also the book’s official hub, statlearning.com.
