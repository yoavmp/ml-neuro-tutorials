# Introduction

These are the practice-session materials for **Machine Learning for
Neuroscience**. Each practice notebook follows a short PowerPoint presentation,
which is available on Moodle; the notebook is where those ideas are put to work
on real data.

## Using the notebooks

The notebooks can be worked through together during the in-class practice
session, or on your own at home at your own pace. Each one is written to be
read from top to bottom.

Some activities are interactive and run directly on this published page, with
nothing to install. For the rest, you are encouraged to run the code yourself
and to experiment by changing it: every notebook provides a **Colab** link and a
downloadable `.ipynb` file for exactly that.

## About the questions

Questions are placed throughout each notebook, and some of them come *before*
the explanation or result they refer to. This is deliberate: committing to an
answer first, and then checking it, builds a deeper understanding than reading
the conclusion straight away. The reasoning these questions ask for is close to
what course assessment and exam questions expect.

Some questions have a revealable guide that walks through the reasoning. Others
are genuinely open and have no single correct answer.
