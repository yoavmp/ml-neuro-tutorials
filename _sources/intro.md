# Introduction

Welcome to the tutoring materials for **Machine Learning for Neuroscientists**.

These tutorials accompany the course lectures and provide guided, hands-on
practice with statistical learning methods using neuroscientific datasets.

Each tutorial contains:

- Short conceptual reviews
- Executable Python examples
- Questions to answer before running code
- Programming exercises
- Interpretation and reflection questions
- Optional extension exercises

The tutorials can be used for both classroom participation and independent
study.
